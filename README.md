# UFO 피규어 뽑기 시뮬레이터

집게 2개짜리 SEGA식 UFO 캐처에서 두 봉 위에 걸쳐 놓은 피규어 박스(다리 걸치기·하시와타시) 뽑기를 PC로 연습하는 3D 물리 시뮬레이터입니다.

## 실행
`index.html`을 다운로드해서 브라우저(Chrome/Edge)로 더블클릭하면 바로 실행돼요. 인터넷 연결이 필요 없습니다.

## 조작
- `C` 또는 동전 버튼: 돈 넣기 (1판 ₩1,000, ₩5,000은 6판)
- ① 버튼 (`Z` / `→`): 누르고 있는 동안 오른쪽으로 이동, 떼면 멈춤 (한 판에 한 번만)
- ② 버튼 (`X` / `↑`): 누르고 있는 동안 안쪽으로 이동, 떼면 집게가 내려감
- `V`: 시점 전환 (정면/오른쪽/왼쪽/위/자유)
- `R`: 직전 판 되돌리기 (연습용)

## 개발
```
npm install
npm run build   # src/ → index.html (단일 파일)
npm test        # 헤드리스 물리 테스트
```
- `src/sim.js`: cannon-es 물리 + 집게 상태 머신
- `src/scene.js`: three.js 렌더링
- `src/main.js`: UI/입력, `src/sound.js`: 효과음
